日期：2026-10-30。此提交只提供獨立、只讀的 Python adapter 與靜態來源 catalog；尚未接入 Lab Pro 研究圖、設定頁、服務或正式資料庫。

## 官方來源與授權

- [FinMind Free 價格與授權](https://finmind.github.io/Pricing/)：匿名 Free 300 次／小時，註冊會員 600 次／小時；現金流量表、綜合損益表、資產負債表、相關新聞列於 Free。僅非商業用途，須標示 FinMind，禁止再散布原始資料或建立鏡像 API。
- [FinMind 基本面文件](https://github.com/FinMind/FinMind-Doc/blob/master/docs/tutor/TaiwanMarket/Fundamental.md)：財報 `date` 為期末日，不是公布日；損益表金額為單季、現金流量表為年初至該季累計、資產負債表為期末時點。金額值以新台幣元表示，EPS 為每股元，`_per` 是百分比。合併／個體口徑在本次 API 列中未得到可核實標誌，保留 `unknown`。
- [FinMind 資料集清單](https://github.com/FinMind/FinMind-MCP/blob/master/knowledge/datasets.md)：`TaiwanStockNews` Free，回傳 `date`、`stock_id`、`title`、`link`、`source`。匿名實測沒有摘要或全文。帶 `end_date` 時 API 400 明示只送一天、需不帶 `end_date`，模組只允許單日查詢。
- [TWSE OpenAPI](https://openapi.twse.com.tw/) 的 `GET /v1/opendata/t187ap04_L` 與 [TPEx OpenAPI](https://www.tpex.org.tw/openapi/) 的 `GET /openapi/v1/mopsfin_t187ap04_O` 是每日上市／上櫃重大訊息集合；本次沒有證實歷史查詢契約。`發言日期`、`發言時間`、`事實發生日` 不是已核實的公開時間或法定日期。MOPS 歷史公告在此候選中為 `unsupported`，不爬取或繞過封鎖。

## 呼叫契約

```python
from engine.tw_free_sources import FreeTaiwanSources
from engine.tw_source_catalog import get_source_catalog

sources = FreeTaiwanSources()
cutoff = "2026-10-30T23:59:59+08:00"  # ISO 8601，必須含時區
income = sources.fetch_finmind_dataset("income", "2330", "2025-01-01", end_date="2025-03-31", as_of=cutoff)
news = sources.fetch_finmind_dataset("news", "6488", "2026-10-29", as_of=cutoff)
announcements = sources.fetch_disclosures("listed", "2330", as_of=cutoff)
catalog = get_source_catalog()
```

`dataset` 只接受 `income|balance|cash_flow|news`；股票代號僅四碼。`market` 只接受 `listed|otc`。URL 固定在模組內，沒有 token 參數或模型呼叫。Transport、clock、sleep、now 可注入供測試。服務整合前應另設跨進程配額與持久快取；現有實作只有單實例記憶體快取、每次請求最小 1 秒間隔、最多一次暫態重試。402/403 不重試；429/5xx 有上限退避（最多 4 秒），`retry_after` 如有純秒數則回報。

`FetchResult.records` 只放 `published_at` 可核實且不晚於 `as_of` 的列；`unknown_records` 是可展示但 **不得** 投入歷史研究圖的列。三種 FinMind 財報與本次新聞、兩種公告來源都沒有可核實的 `published_at` 時區與公開時間，因此本次樣本都在 `unknown_records`。`data_period` 可為財報期末、新聞日期或公告事實日，絕不可替代 `published_at`。每列含 `source_url`、`fetched_at`、`data_period`、`published_at`、`as_of`、`availability`；財報另含 `unit`、`period_basis`、`single_quarter_value`、`single_quarter_derivation`、`consolidation`。現金流不擅自換算單季，標 `year_to_date_cumulative`，`single_quarter_value=None`；若未來要算，須取同公司同年度相鄰季度及相同口徑。

`status=ok` 只表示 API 回應可解析，不表示有可供研究圖使用的列；`empty` 是該範圍未命中，不能推論公司從未公告。`gaps` 指明 `published_at_unknown`、`no_matching_rows` 等缺口。`cache_hit` 表示有效快取；`cache_stale` 表示過期快取曾存在但 **未** 當新資料供應，網路失敗則 `status=unavailable` 且結果列為空。`rate_limited`、`retry_after`、`http_status` 供 UI 呈現限流／權限錯誤，不可無限重試。`fetched_at` 是實際成功抓取時間，快取命中保留原時間；catalog 的 `verified_at` 是文件與抽樣核對日期，**不是** runtime 健康或最後成功時間。

## 測試與交接

`python3 -m unittest engine.tests.test_tw_free_sources -v` 覆蓋財報口徑、新聞單日契約、公告時間未知、前視排除、402/403 不重試、429 退避、過期快取、輸入驗證及 catalog；`python3 -m compileall -q engine/tw_free_sources.py engine/tw_source_catalog.py` 檢查語法。Sonnet 在其最新候選堆疊接 hook 時，先決定如何獨立核實公開時間；未解決時只能展示 `unknown_records` 與來源限制，不能把它送進完整研究圖。設定頁可讀 `get_source_catalog()`，runtime 健康應由實際抓取結果另行維護。
